Open-Source Technologies & Foundations

The battle-tested open-source libraries that power our front and back ends.

Chart.js

Provides the high-performance HTML5 canvas rendering for real-time speed traces, acceleration graphs, and dynamic telemetry curves.

SortableJS

Powers the silky smooth drag-and-drop dashboard module customisation, allowing drivers to rearrange widgets to their exact preference.

Flask & Werkzeug

The Python microframework backbone delivering strict parameterised SQLite queries, scrypt password hashing, and secure session management.

fpdf2

Generates automated PDF journey summary reports complete with route details, average speeds, overspeed events, and stats.

DOMPurify & Marked

Enables safe, sanitised client-side Markdown rendering for in-app connection guides and live README project documentation.

Cloudflare

Powers zero-port Cloudflare Tunnels, edge TLS termination, and WAF protection, keeping the public dashboard fast and protected.
